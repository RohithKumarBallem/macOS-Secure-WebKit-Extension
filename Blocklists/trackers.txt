# Secure WebKit tracker domains.
#
# One entry per line. A domain also covers its subdomains. Accepted formats:
#   example.com            plain domain
#   0.0.0.0 example.com    hosts file
#   ||example.com^         Adblock-style domain anchor
#   @@example.com          allowlist (beats any blocklist entry)
#
# This is a small curated starter set of well-known advertising, analytics and
# session-recording domains. It is deliberately conservative: only domains whose
# sole purpose is tracking/advertising, so blocking them should not break sites.
# For broader coverage append a larger list (EasyPrivacy, Peter Lowe's hosts)
# and run `make rules`.
